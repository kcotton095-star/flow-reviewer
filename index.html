Setup checklist

Zapier and Financial Cents handoff

1. Mark onboarding complete in Financial Cents, then use Zapier or a webhook step to call POST /api/onboarding-trigger.
2. Pass client name, email, phone, onboarding completion time, Financial Cents client ID, and service type.
3. Include the shared secret header x-flow-reviewer-secret and the event type onboarding_completed.
4. Send the client to the Stripe checkout link as a separate optional monthly subscription.
5. On Stripe payment success, the webhook at /api/stripe-webhook activates the client and sets the paid-through date.
Sample payload 
{
  "client_name": "Acme Plumbing",
  "client_email": "owner@acmeplumbing.com",
  "client_phone": "+1-555-111-2222",
  "onboarding_completed_at": "2026-05-24T13:00:00Z",
  "financial_cents_client_id": "fc_12345",
  "service_type": "Bookkeeping",
  "event_type": "onboarding_completed"
}

Routing rule

Ratings of 4–5 stars → redirect to Google review URL. Ratings of 1–3 stars → route feedback privately to the configured email address.
